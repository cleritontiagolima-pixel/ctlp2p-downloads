# CTL P2P — Downloads

Espaço dedicado aos downloads do aplicativo CTL P2P (Android APK).

## Instalação

1. Baixe o arquivo **ctlp2p.apk** na [aba de Releases](../../releases).
2. Abra o arquivo no aparelho e autorize a instalação (fontes desconhecidas).

Este repositório contém apenas os binários distribuídos aos clientes.
